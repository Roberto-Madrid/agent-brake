# Operations added in 0.3

All examples assume a supported Python and the same `TOKEN_POLICE_HOME` as your host. Run the CLI through `scripts/launch.sh` when interpreter discovery is needed. Routine commands make no model calls or network requests.

## Status and findings

```sh
python scripts/tp.py status
python scripts/tp.py status --project my-project --task my-task
python scripts/tp.py findings
```

`spend_microusd` stays null when any cost is unknown or no receipts exist. `known_subtotal_microusd` is explicitly partial. Remaining budgets include managed admissions and attributed legacy reservations; limits come from managed policy. An unlimited or unconfigured budget remains null. Project/task filtering scopes costs and reservations; hook health and findings describe the local ledger as a whole. Findings rank capped local evidence, not estimated dollar savings. They never store raw command text.

Hook health means the adapter received an event, not that every tool or model request was captured. Host trust is not automatically inspected. Synthetic launcher tests are labelled and do not set `runtime_observed`.

`session_warning_pct` (default 80) records one deduplicated finding as a session approaches its configured tool-call cap. It sends no automatic model message. The actual cap is unchanged. Task-scoped expiring exceptions use the existing `exception --task --rule --expires --reason` command and are included in the audit trail; organization policy restricts their creation to administrators. Use `session:<host session ID>` for a hook task unless `TOKEN_POLICE_TASK` is set.

## References and compaction

`SessionStart` and `PreCompact` invalidate reference reuse. Each event also advances a ledger-wide context epoch to cover explicit task IDs that cannot be mapped to a host session. This conservative reset may re-read another active task's reference; it never suppresses content after a context change. If hooks were unavailable, use `--force` after context loss.

Long selected lines return at most 16,000 UTF-8 bytes. When `next_byte_offset` is present, continue with the same `--offset`, `--lines`, and `--byte-offset` value. Once it is null, advance to `next_offset` if present. Do not advance past a long line until its byte continuation is complete. A changed source hash invalidates reuse; discard prior fragments and restart the selection if the hash changes mid-pagination.

## Pricing and reconciliation

Legacy explicit model rate maps still work. They receive a content digest so the pricing basis can be identified. Versioned rate files have exactly `version`, `effective_date` (ISO date), `source_url` (HTTPS), and `models` (the same model rate map). Rates are USD per million tokens, supplied by the operator; the plugin does not fetch current prices. Example values in tests are synthetic.

Omitted cache-read counts remain unknown. Anthropic inclusive input also stays unknown when its cache components are omitted. OpenAI cache-write defaults to zero for this adapter's supported usage contract; reasoning tokens are already included in output and are not added again. Missing cost components prevent an estimate.

Import normalized receipts into a new pilot state when upgrading from 0.2 if the old adapter filled omitted cache fields with zero. Existing event IDs and costs are immutable; conflicting reimports are rejected rather than silently changing past accounting. Archive old state locally and keep the cohorts separate.

```sh
python scripts/tp.py reconcile statement.json --workload log-review --cohort treatment
python scripts/tp.py report --workload log-review
```

The statement contains `billed_total_microusd` and an `evidence` pointer. You attest that it covers the selected workload and cohort. Reconciliation reports differences and never overwrites receipts. A matched total does not prove every request was captured.

The pilot report includes mean/p95 task elapsed time and human effort when supplied in outcomes. `release_evidence_complete` describes data availability, not a recommendation to ship a control. Continue reviewing cost, quality and operational regressions; use `rule-report`/`rule-evaluate` for configured rollback thresholds. `--attest-complete` remains an explicit operator assertion, never an inferred property.
